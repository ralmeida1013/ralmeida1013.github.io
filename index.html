Enhanced Tetris

Ruby

As a project, I took a working build of a version of the classic puzzle game Tetris and added a handful of modifications to the rules of the game, in addition to new gameplay features using the Ruby programming language. Within this new version of Tetris with enhancements implemented, there are three new pieces in addition to the classic seven pieces. A feature where the player can flip a piece 180 degrees has been added, as well as a "cheat" mode where the next piece is a 1 x 1 square, but only if the player has 100 or more points as it costs 100 points to use. Working on this project, I was able to refine my skills in using dynamic dispatch, modifying subclasses, and enhancing my skills in Object-Oriented Programming.
